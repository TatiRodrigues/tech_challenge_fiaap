# 🔖 Versionamento

Política de versionamento do projeto.

## Semantic Versioning (SemVer)

Formato: `MAJOR.MINOR.PATCH`

### MAJOR (X.0.0)
- Breaking changes
- Incompatibilidade com versão anterior
- Incrementar quando há mudanças não-retrocompatíveis

### MINOR (1.X.0)
- Novas funcionalidades
- Retrocompatível
- Incrementar quando adiciona feature

### PATCH (1.0.X)
- Bug fixes
- Retrocompatível
- Incrementar quando corrige bug

## Exemplos

```
1.0.0 → 1.0.1  (bug fix)
1.0.0 → 1.1.0  (nova feature)
1.0.0 → 2.0.0  (breaking change)
```

## Release

- Versão atual: **1.0.0**
- Próximas: 1.1.0, 2.0.0
