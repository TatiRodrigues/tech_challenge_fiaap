# ⚡ Solução Rápida - 5 Minutos

Começe a usar o Alecrim Wallet - seu gerenciador de transações inteligente em 5 minutos.

## 🚀 Setup (2 min)

```bash
# 1. Clone
git clone https://github.com/TatiRodrigues/tech_challenge_fiaap.git
cd alecrim-wallet

# 2. Instale
npm install

# 3. Inicie
npm run dev
```

Acesse: http://localhost:3000
