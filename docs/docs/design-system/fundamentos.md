# Fundamentos

Elementos base do Design System.

## 🌈 Paleta de Cores

### Cores Principais

| Cor | Hex | Uso |
|-----|-----|-----|
| Primary | #0066CC | CTAs, Links, Highlights |
| Success | #22C55E | Confirmação, Status Ativo |
| Error | #EF4444 | Erros, Status Crítico |
| Warning | #F59E0B | Avisos, Atenção |

### Cores Neutras

```
Gray-50    #F9FAFB
Gray-100   #F3F4F6
...
Gray-900   #111827
```
