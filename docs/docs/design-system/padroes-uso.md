# Padrões de Uso

Padrões de interação e animação.

## Estados

Todos os componentes suportam:
- Normal
- Hover
- Focus
- Active
- Loading
- Disabled

## Animações

- **Fade**: Entrada/saída
- **Slide**: Movimento
- **Pulse**: Carregamento
- **Scale**: Zoom

## Interações

### Formulários
- Validação em tempo real
- Mensagens de erro
- Estados de sucesso

### Confirmação
- Modal de confirmação
- Ações destrutivas protegidas
