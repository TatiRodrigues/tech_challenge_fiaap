# ♿ Acessibilidade

Diretrizes de acessibilidade WCAG 2.1 AA.

## Conformidade

✅ WCAG 2.1 AA (padrão mínimo)

## Requisitos

### Contraste
Mínimo 4.5:1 para textos normais

### Navegação por Teclado
- Tab: Próximo elemento
- Shift+Tab: Anterior
- Enter/Space: Ativar
- Escape: Fechar modal

### Leitores de Tela
- ARIA labels apropriadas
- Semantic HTML
- Descrições de imagem

## Checklist

- ✅ Contraste adequado
- ✅ Labels para inputs
- ✅ ARIA attributes
- ✅ Focus visible
- ✅ Teclado navegável
