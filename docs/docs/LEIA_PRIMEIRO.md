# 📖 Leia Primeiro

Informações essenciais para começar.

## 🎯 O que é a Alecrim Wallet?

Seu gerenciador de transações inteligente com:
- Interface intuitiva e responsiva
- Componentes reutilizáveis
- Design system consistente
- Documentação completa e interativa

## 📊 Stack Tecnológico

| Tecnologia | Versão | Uso |
|-----------|--------|-----|
| **Next.js** | 16.1.6 | Framework React |
| **React** | 19.2.3 | UI Library |
| **TypeScript** | 5+ | Type Safety |
| **Tailwind CSS** | 4+ | Styling |
| **Docusaurus** | 3.10.0 | Documentação |

## 🚀 Comece em 3 Passos

### 1. Clone e Install
```bash
git clone <repo-url>
cd alecrim-wallet
npm install
```

### 2. Inicie o Dev Server
```bash
npm run dev
```

### 3. Acesse no Navegador
```
http://localhost:3000
```

## 🎮 Recursos Principais

### 1. Componentes Interativos
Cada componente tem:
- ✅ Configurador (mude propriedades em tempo real)
- ✅ Exemplos (casos de uso reais)
- ✅ API Completa (todas as props documentadas)

### 2. Design System
Sistema completo incluindo:
- Paleta de cores
- Tipografia
- Espaçamento
- Ícones
- Componentes

### 3. Acessibilidade
Todos os componentes:
- Conformes com WCAG 2.1 AA
- Navegação por teclado
- Suporte a leitores de tela

## 🆘 Troubleshooting

**Erro ao instalar?**
```bash
rm -rf node_modules package-lock.json
npm install
```

**Porta 3000 em uso?**
```bash
npm run dev -- -p 3001
```

**Problema na documentação?**
```bash
cd docs
npm run clear
npm run start
```
