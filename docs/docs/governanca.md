# 🏛️ Governança

Governança e processo de decisões.

## Estrutura

- **Maintainers**: Gerenciam o projeto
- **Contributors**: Contribuem com código
- **Community**: Usa e fornece feedback

## Decisões

### Features Novas
1. Abra uma issue com proposta
2. Diskuta com maintainers
3. Se aprovado, implemente
4. Submit PR

### Breaking Changes
Requer votação da comunidade e aumenta minor version.

### Versioning

Segue SemVer:
- `MAJOR.MINOR.PATCH`
- `1.2.3` = v1 major, 2 minor, 3 patch
